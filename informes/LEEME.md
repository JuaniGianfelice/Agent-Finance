# Informes

Acá se guarda un archivo `AAAA-MM-DD.md` por cada corrida del agente.

No edites estos archivos: son el registro de qué mostraban los números ese día. Sirven para dos cosas:

1. El agente compara con el informe de ayer para marcar qué señales son **nuevas**.
2. Dentro de unos meses vas a poder mirar para atrás y ver si las señales que te dio tenían sentido.
